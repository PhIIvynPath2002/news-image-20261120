A one-page newspaper-style image summing up the world news of Friday 20 November 2026, built from the full day's reporting. This improved version (v2) leads with the ICJ ruling that Myanmar committed genocide against the Rohingya, updates Cyclone Akvan with its actual landfall near Gopalpur, and adds the day's daytime stories the morning edition missed: the Russian barrage damaging embassies and a cathedral in Kyiv, the Houthi missile strike on Riyadh's tallest tower, the global stock slide (Nikkei −4.8%, S&P down a fifth day) despite Anthropic's record IPO debut, and the White House firing its cyber chief after a week of tech outages. The image is drawn by draw.py (Pillow) and main.py copies it to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
